# Pizzaria La Franchesca (Front-end Website)

*[Leia em Português](#pizzaria-la-franchesca-desenvolvimento-front-end)*

A responsive website developed from scratch as a practical project during my HTML, CSS, Bootstrap, and JavaScript training at Senac.

The project simulates a commercial restaurant website, focusing on responsive design, user experience, interactive interfaces, and DOM manipulation.

## Live Demo

[Access the website](https://wilianferraz.github.io/ProjetoPizzaria/)

## Technologies Used

- **HTML5** (Page structure and semantic elements)
- **CSS3** (Custom styling, media queries, transitions, and visual effects)
- **JavaScript** (DOM manipulation and event handling)
- **Bootstrap 5** (Responsive layouts and interface components)
- **AOS** (Animate On Scroll library)
- **Font Awesome** (Icons)
- **Google Fonts** (Custom typography)
- **GitHub Pages** (Website deployment)

## Features

- Responsive layout for different screen sizes.
- Navigation bar with dynamic transparency based on scroll position.
- Interactive carousel for featured products.
- Pizza catalog with descriptions, sizes, and prices.
- Product size selection using radio buttons.
- Demonstration shopping cart confirmation modal.
- Interactive hover effects and scroll animations.
- Restaurant information, services, and blog preview sections.

## Project Structure

- `index.html`: Main page containing the navigation bar, carousel, product catalog, and restaurant information.
- `contato.html`: Contact page.
- `css/style.css`: Custom styling, responsive layouts, transitions, and visual effects.
- `js/detalhes.js`: JavaScript functions for image manipulation and dynamic navigation bar behavior.
- `img/`: Directory containing images, banners, logos, icons, and other visual assets.

## How to Run

1. Clone the repository:

       git clone https://github.com/WilianFerraz/ProjetoPizzaria.git

2. Access the project directory:

       cd ProjetoPizzaria

3. Open the `index.html` file in your preferred web browser.

### Notes

- No dependency installation or build process is required.
- An internet connection is recommended to load external libraries, fonts, and icons.
- The shopping cart interface is demonstrative and does not include order processing or payment integration.

## Future Improvements

- Implementation of a functional shopping cart using JavaScript.
- Automatic price calculation and product quantity management.
- Improvements in accessibility and mobile responsiveness.
- Implementation of contact form validation.

# Pizzaria La Franchesca (Desenvolvimento Front-end)

*[Read in English](#pizzaria-la-franchesca-front-end-website)*

Site responsivo desenvolvido do zero como projeto prático durante minha formação em HTML, CSS, Bootstrap e JavaScript no Senac.

O projeto simula o site comercial de uma pizzaria, com foco em design responsivo, experiência do usuário, interfaces interativas e manipulação do DOM.

## Demonstração Online

[Acesse o site](https://wilianferraz.github.io/ProjetoPizzaria/)

## Tecnologias Utilizadas

- **HTML5** (Estruturação de páginas e elementos semânticos)
- **CSS3** (Estilização personalizada, media queries, transições e efeitos visuais)
- **JavaScript** (Manipulação do DOM e gerenciamento de eventos)
- **Bootstrap 5** (Layouts responsivos e componentes de interface)
- **AOS** (Biblioteca de animações durante a rolagem)
- **Font Awesome** (Ícones)
- **Google Fonts** (Tipografia personalizada)
- **GitHub Pages** (Publicação do site)

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela.
- Barra de navegação com transparência dinâmica conforme a rolagem.
- Carrossel interativo para apresentação de produtos em destaque.
- Catálogo de pizzas com descrições, tamanhos e preços.
- Seleção de tamanhos dos produtos utilizando radio buttons.
- Modal demonstrativo de confirmação de adição ao carrinho.
- Efeitos hover interativos e animações durante a rolagem.
- Seções institucionais, serviços e prévia de blog.

## Estrutura do Projeto

- `index.html`: Página principal contendo a barra de navegação, carrossel, catálogo de produtos e informações institucionais.
- `contato.html`: Página de contato.
- `css/style.css`: Estilização personalizada, layouts responsivos, transições e efeitos visuais.
- `js/detalhes.js`: Funções JavaScript para manipulação de imagens e comportamento dinâmico da barra de navegação.
- `img/`: Diretório contendo imagens, banners, logotipos, ícones e demais recursos visuais.

## Como Executar

1. Clone o repositório:

       git clone https://github.com/WilianFerraz/ProjetoPizzaria.git

2. Acesse o diretório do projeto:

       cd ProjetoPizzaria

3. Abra o arquivo `index.html` no navegador de sua preferência.

### Observações

- Não é necessário instalar dependências ou realizar um processo de compilação.
- Recomenda-se conexão com a internet para carregar bibliotecas externas, fontes e ícones.
- A interface do carrinho é demonstrativa e não possui processamento de pedidos ou integração com pagamentos.

## Melhorias Futuras

- Cálculo automático de preços e gerenciamento da quantidade de produtos.
- Melhorias na acessibilidade e responsividade em dispositivos móveis.
- Implementação de validação no formulário de contato.
